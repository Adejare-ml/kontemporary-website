# Kontemporary Konsulting Ltd — Website Redesign

> **Aesthetic:** Quiet Authority — Editorial Minimalism × African Prestige

A complete multi-page website redesign for [Kontemporary Konsulting Ltd](https://kontemporary.net.ng), a 30+ year ICT consultancy based in Abuja, Nigeria.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage — hero, stats, services, leadership, news, partners, CTA |
| `about.html` | About — story, vision, mission, leadership spotlight |
| `services.html` | Services — Komputers, Konsulting, Kreativities (detailed) |
| `news-room.html` | News Room — 12 articles with category filter |
| `contact.html` | Contact — form, sidebar, info blocks |
| `css/style.css` | Shared design system — tokens, components, animations, responsive |
| `js/main.js` | Interactions — preloader, nav scroll, mobile menu, counters, reveals |

## Design System

- **Colors:** Ink `#0E1117` · Linen `#F9F6F0` · Burnished Gold `#A67C52`
- **Fonts:** Cormorant Garamond (display) · DM Sans (body) · Bebas Neue (stats)
- **Animations:** K-lettermark preloader · scroll reveals · counter animation · news ticker · SVG network art

## Usage

Open `index.html` in any browser — no build step, no dependencies. All pages link to each other relatively.

## Issues Fixed (30 total)

Original site audit identified 30 issues including: no hero headline, news ticker before context, zero CTAs above fold, nav duplicated 3×, Dr. Jimson invisible on homepage, stock images for Vision/Mission, partner logos with no context, "Powered by" footer credit, and more.
